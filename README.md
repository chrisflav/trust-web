# trust-web

The trust frontend: a React application that reads a static index produced by
`trust export` and lets you walk a declaration's definitional dependencies, read
the declarations themselves, and see the human judgements and certificates
attached to them.  Because the index is static, a deployed instance is a plain
set of files behind a web server.  Part of
[chrisflav/trust](https://github.com/chrisflav/trust).
